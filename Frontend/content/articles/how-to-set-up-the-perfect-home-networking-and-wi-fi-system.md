Streaming, work, cameras, and a smart home share one network. If that network is weak, everything else feels broken.

### The pieces

- **Modem:** the link to your ISP
- **Router:** traffic and Wi-Fi
- **Access points:** extra coverage on another floor or a long house
- **Ethernet:** still the most stable path for TVs, consoles, and desks

A working [home network](/service/home-networking-and-wi-fi/) is these parts planned together, not a single box in a cabinet.

### Choose the router for the house

Match bands and generation to the device count. Dual-band (2.4 GHz and 5 GHz) covers most homes. 2.4 GHz reaches farther through walls; 5 GHz is faster and shorter. Wi-Fi 6 handles denser lists better than older standards. MU-MIMO helps when many devices talk at once.

Mesh is the usual fix for villas, thick walls, or outdoor seating. Nodes share one network name. You walk between floors without hopping SSIDs. Add a node where coverage drops — don't stack consumer extenders on a weak signal.

### Secure it

Change the default admin login on day one. Use WPA3 if the router supports it, WPA2 if not. Long password. Guest network for visitors so they stay off cameras and files.

### When it still fails

Reboot, then check firmware. Slow speeds are often interference or an ISP issue, not a new router. Dead rooms need another node or a cable.
